# Nuestra Galaxia — Versión 2

Página romántica estática con 17 recuerdos.

## Estructura
- `index.html`
- `style.css`
- `script.js`
- `fotos/foto01.jpg` ... `foto17.jpg`

## Fotos
Coloca tus 17 fotos en la carpeta `fotos` con esos nombres. Si tus archivos tienen otros nombres, cambia la propiedad `image` en `script.js`.

## Frases
En `script.js`, dentro de `memories`, puedes cambiar `label`, `title` y `phrase`.

## Ejecutar
Abre la carpeta en Visual Studio Code y abre `index.html`, preferiblemente con Live Server.

## GitHub Pages
Es un sitio completamente estático, por lo que posteriormente puedes subir los archivos directamente a un repositorio y activar GitHub Pages.

La página incluye una pantalla de entrada, zoom cinematográfico, 17 planetas/estrellas interactivos, fotos, frases, navegación y un cierre final.
